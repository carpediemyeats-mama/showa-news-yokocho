昭和ニュース横丁 PWA v1

1. このフォルダ内のファイルをすべて GitHub Pages などの HTTPS 対応静的サイトへ配置してください。
2. 公開URLをChrome等で開き、ホーム画面に追加／アプリをインストールを選択します。
3. 毎週 news.json を差し替えると、ゲーム起動時に新しい問題を読み込みます。
4. 学習記録はブラウザ内に保存され、別端末とは同期しません。
5. オフラインでは最後に正常取得したニュースを利用できます。初回は通信が必要です。
6. news.json のニュースごとに共通2問＋長男2問、選択肢4つ、正答は0〜3のインデックス。
7. 現在の収録2件はデモ用教材で、最新ニュースではありません。
8. ファイルを直接開くだけではPWAインストールや自動更新は動きません。HTTPS公開が必要です。
9. サイトデータの消去で学習記録も消える場合があります。
